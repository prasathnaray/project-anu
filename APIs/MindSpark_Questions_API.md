# MindSpark Challenge Questions API

Base URL:

```text
http://localhost:4004/api/v1
```

All endpoints are mounted behind the existing `Authenticate` middleware.

```http
Authorization: Bearer <access_token>
```

## Access

| Role | Access |
| --- | --- |
| `99` | Create, upload assets, read, update, delete |
| `101` | Create, upload assets, read, update, delete |
| `102` | Create, upload assets, read, update, delete |
| `103` | Read questions and attempt details only |

The API stores configurable challenge questions in `mind_spark_questions`. It supports the challenge question types used by Image Interpretation:

| Type | Use |
| --- | --- |
| `type1` | Find/select the correct image or option |
| `type2` | Upload/interpreted image answer |
| `annotation1` | Annotation challenge |
| `annotation2` | Annotation challenge |
| `measurement` | Measurement/caliper challenge |
| `MCQ` | Generic multiple-choice question |

## Endpoint Summary

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/mind-spark-questions` | Create or upsert one or more questions |
| `POST` | `/mind-spark-question-assets` | Upload an image asset for question configuration |
| `GET` | `/mind-spark-questions?resource_id=...` | List configured questions for a resource |
| `GET` | `/mind-spark-attempt-details?resource_id=...` | Get latest submitted answers joined with configured questions |
| `PUT` | `/mind-spark-questions/:question_id` | Update one question |
| `DELETE` | `/mind-spark-questions/:question_id` | Soft-delete one question |
| `POST` | `/create-question` | Legacy alias for `POST /mind-spark-questions` |

## Data Model

Question rows contain:

| Field | Type | Required on create | Notes |
| --- | --- | --- | --- |
| `question_id` | UUID | No | Generated by database. |
| `resource_id` | UUID | Yes | Resource/activity ID. Can be sent at payload root for bulk create. |
| `mindspark_no` | number | No | Defaults to `1`. Also accepts `mindsparkNo`. |
| `question_no` | number | Yes | Unique with `resource_id` and `mindspark_no`. Also accepts `questionNo`. |
| `question_type` | string | No | Defaults to `MCQ`. Also accepts `questionType`. |
| `prompt` | string | Yes | Also accepts `question_query` or `question`. |
| `options` | JSON array | No | Defaults to `[]`. Also accepts `options_available`. |
| `correct_answer` | JSON | Yes | Also accepts `correctAnswer` or `answer`. |
| `feedback_correct` | string | No | Also accepts `feedbackCorrect`. |
| `feedback_wrong` | string | No | Also accepts `feedbackWrong`. |
| `assets` | JSON array | No | Uploaded/reference images or other asset metadata. |
| `metadata` | JSON object | No | Type-specific configuration, for example expected landmarks. |
| `is_active` | boolean | No | Defaults to `true`. Also accepts `isActive`. |

`POST /mind-spark-questions` performs an upsert. If a row already exists for the same `resource_id`, `mindspark_no`, and `question_no`, it updates that row.

## 1. Create Or Upsert Questions

```http
POST /mind-spark-questions
Content-Type: application/json
```

### Bulk Payload

```json
{
  "resource_id": "e196c6db-dc0b-4ebd-93b2-10a2125188e5",
  "mindspark_no": 1,
  "questions": [
    {
      "question_no": 1,
      "question_type": "type1",
      "prompt": "Select the image that shows the correct transthalamic plane.",
      "options": [
        {
          "key": "a",
          "text": "Image A",
          "image_url": "https://example.com/image-a.png"
        },
        {
          "key": "b",
          "text": "Image B",
          "image_url": "https://example.com/image-b.png"
        }
      ],
      "correct_answer": {
        "key": "a",
        "timeframe": "30 seconds"
      },
      "feedback_correct": "Correct. The CSP, thalami, and falx are visible.",
      "feedback_wrong": "Review the required landmarks for the transthalamic plane."
    },
    {
      "question_no": 2,
      "question_type": "annotation1",
      "prompt": "Annotate the required BPD landmarks.",
      "correct_answer": {
        "expected_label_count": 3
      },
      "assets": [
        {
          "type": "reference_image",
          "url": "https://example.com/reference.png"
        }
      ],
      "metadata": {
        "expected_landmarks": ["CSP", "Thalami", "Falx cerebri"]
      }
    }
  ]
}
```

### Single-Question Payload

```json
{
  "resource_id": "e196c6db-dc0b-4ebd-93b2-10a2125188e5",
  "mindspark_no": 1,
  "question_no": 3,
  "question_type": "measurement",
  "prompt": "Measure the BPD value using the correct caliper placement.",
  "options": [],
  "correct_answer": {
    "value": 52.4,
    "unit": "mm",
    "tolerance": 1.0
  },
  "metadata": {
    "measurement_type": "BPD"
  }
}
```

Success response:

```json
{
  "status": "Success",
  "code": 200,
  "message": "Mindspark questions saved successfully",
  "data": [
    {
      "question_id": "9bf60fd6-e0df-4549-b7b2-bfb51a0f8858",
      "resource_id": "e196c6db-dc0b-4ebd-93b2-10a2125188e5",
      "mindspark_no": 1,
      "question_no": 1,
      "question_type": "type1",
      "prompt": "Select the image that shows the correct transthalamic plane.",
      "options": [],
      "correct_answer": { "key": "a" },
      "feedback_correct": null,
      "feedback_wrong": null,
      "assets": [],
      "metadata": {},
      "is_active": true,
      "created_by": "admin@example.com",
      "created_at": "2026-07-15T10:00:00.000Z",
      "updated_at": "2026-07-15T10:00:00.000Z"
    }
  ]
}
```

Validation errors:

```json
{
  "status": "Bad Request",
  "code": 400,
  "message": "resource_id is required"
}
```

Possible validation messages:

- `questions should not be empty`
- `resource_id is required`
- `question_no is required`
- `prompt is required`
- `correct_answer is required`

## 2. Upload Question Asset

Uploads an image to Supabase storage and returns metadata that can be placed in `assets`, `options`, or `metadata`.

```http
POST /mind-spark-question-assets
Content-Type: multipart/form-data
```

Form data:

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `image` | file | Yes | Must have an `image/*` MIME type. |

The upload limit defaults to `10 MB` and can be changed with `MAX_MINDSPARK_ASSET_SIZE_MB`.

Example:

```bash
curl -X POST "http://localhost:4004/api/v1/mind-spark-question-assets" \
  -H "Authorization: Bearer <token>" \
  -F "image=@./question-option-a.png"
```

Success response:

```json
{
  "status": "Success",
  "code": 200,
  "message": "Mindspark asset uploaded successfully",
  "data": {
    "filename": "1780000000000-123456789.png",
    "original_name": "question-option-a.png",
    "storage_path": "mindspark/admin_example.com/1780000000000-123456789.png",
    "public_url": "https://example.supabase.co/storage/v1/object/public/question-images/mindspark/admin_example.com/1780000000000-123456789.png",
    "mime_type": "image/png",
    "size": 12345
  }
}
```

Error responses:

```json
{
  "status": "Bad Request",
  "code": 400,
  "message": "image file is required"
}
```

```json
{
  "status": "Bad Request",
  "code": 400,
  "message": "Only image files are allowed"
}
```

## 3. Get Questions

```http
GET /mind-spark-questions?resource_id=<resource_id>&mindspark_no=1
```

Query parameters:

| Parameter | Required | Notes |
| --- | --- | --- |
| `resource_id` | Yes | Resource/activity ID. |
| `mindspark_no` | No | Filters by MindSpark number when supplied. |
| `include_inactive` | No | Use `true` to include soft-deleted questions. Defaults to active only. |

Example:

```bash
curl -X GET "http://localhost:4004/api/v1/mind-spark-questions?resource_id=e196c6db-dc0b-4ebd-93b2-10a2125188e5&mindspark_no=1" \
  -H "Authorization: Bearer <token>"
```

Success response:

```json
{
  "status": "Success",
  "code": 200,
  "data": [
    {
      "question_id": "9bf60fd6-e0df-4549-b7b2-bfb51a0f8858",
      "resource_id": "e196c6db-dc0b-4ebd-93b2-10a2125188e5",
      "mindspark_no": 1,
      "question_no": 1,
      "question_type": "type1",
      "prompt": "Select the image that shows the correct transthalamic plane.",
      "options": [
        { "key": "a", "text": "Image A", "image_url": "https://example.com/image-a.png" }
      ],
      "correct_answer": { "key": "a" },
      "feedback_correct": "Correct.",
      "feedback_wrong": "Try again.",
      "assets": [],
      "metadata": {},
      "is_active": true
    }
  ]
}
```

Rows are ordered by `mindspark_no`, then `question_no`, then `created_at`.

## 4. Get MindSpark Attempt Details

Returns configured active questions joined with the latest submitted answer for the authenticated user from `activity_submissions`.

```http
GET /mind-spark-attempt-details?resource_id=<resource_id>
```

Query parameters:

| Parameter | Required | Notes |
| --- | --- | --- |
| `resource_id` | Yes | Resource/activity ID. |
| `session_id` | No | When supplied, restricts the lookup to that session. |

Example:

```bash
curl -X GET "http://localhost:4004/api/v1/mind-spark-attempt-details?resource_id=e196c6db-dc0b-4ebd-93b2-10a2125188e5" \
  -H "Authorization: Bearer <token>"
```

Success response with submissions:

```json
{
  "status": "Success",
  "code": 200,
  "data": [
    {
      "question_id": "9bf60fd6-e0df-4549-b7b2-bfb51a0f8858",
      "question_no": 1,
      "question_type": "type1",
      "prompt": "Select the image that shows the correct transthalamic plane.",
      "options": [],
      "correct_answer": { "key": "a" },
      "feedback_correct": "Correct.",
      "feedback_wrong": "Try again.",
      "assets": [],
      "metadata": {},
      "session_id": "021306f8-580b-4634-a809-7796b5843387",
      "option_chosen": "a",
      "is_correct": true,
      "submitted_at": "2026-07-15T10:10:00.000Z"
    }
  ],
  "summary": {
    "session_id": "021306f8-580b-4634-a809-7796b5843387",
    "total_questions": 1,
    "correct_answers": 1,
    "wrong_answers": 0,
    "score_percentage": 100
  }
}
```

Success response when no submission session exists:

```json
{
  "status": "Success",
  "code": 200,
  "data": [],
  "summary": {
    "session_id": null,
    "total_questions": 0,
    "correct_answers": 0,
    "wrong_answers": 0,
    "score_percentage": null
  }
}
```

Notes:

- The endpoint chooses the latest session by `MAX(submitted_at)` unless `session_id` is provided.
- For each question in a session, only the latest submission row is returned.
- Questions are filtered to `is_active = true`.
- The current implementation does not filter attempt details by `mindspark_no`.

## 5. Update One Question

```http
PUT /mind-spark-questions/:question_id
Content-Type: application/json
```

Send only fields that need to change.

Example:

```bash
curl -X PUT "http://localhost:4004/api/v1/mind-spark-questions/9bf60fd6-e0df-4549-b7b2-bfb51a0f8858" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Select the best transthalamic plane image.",
    "correct_answer": { "key": "b" },
    "is_active": true
  }'
```

Success response:

```json
{
  "status": "Success",
  "code": 200,
  "message": "Mindspark question updated successfully",
  "data": {
    "question_id": "9bf60fd6-e0df-4549-b7b2-bfb51a0f8858",
    "prompt": "Select the best transthalamic plane image.",
    "correct_answer": { "key": "b" },
    "is_active": true
  }
}
```

If no row exists:

```json
{
  "status": "Not Found",
  "code": 404,
  "message": "Question not found"
}
```

Note: nullable fields cannot currently be cleared to `null` through this endpoint because updates use `COALESCE`.

## 6. Delete One Question

This is a soft delete. It sets `is_active` to `false`.

```http
DELETE /mind-spark-questions/:question_id
```

Example:

```bash
curl -X DELETE "http://localhost:4004/api/v1/mind-spark-questions/9bf60fd6-e0df-4549-b7b2-bfb51a0f8858" \
  -H "Authorization: Bearer <token>"
```

Success response:

```json
{
  "status": "Success",
  "code": 200,
  "message": "Mindspark question deleted successfully",
  "data": {
    "question_id": "9bf60fd6-e0df-4549-b7b2-bfb51a0f8858",
    "is_active": false
  }
}
```

  "status": "Error",

  "message": "Failed to save Mindspark questions",
  "error": "error details"
